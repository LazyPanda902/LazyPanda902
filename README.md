## About

Former Technical Support Analyst with hands-on experience supporting Windows, macOS, Microsoft 365, Active Directory, MFA, VPN, printers, user accounts, workstation deployment, and remote users.

I have a Computer Science background from UT Dallas and build practical tools around IT support, Linux, Docker, Raspberry Pi infrastructure, account auditing, service monitoring, log analysis, backups, and GitHub automation.

My projects focus on turning repetitive support and homelab work into documented, testable, and reusable workflows.
